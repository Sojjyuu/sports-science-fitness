# Sports Science Fitness Club

เว็บไซต์ต้นแบบสำหรับจัดการสมาชิกฟิตเนส ประเมินข้อมูลสุขภาพ ค้นหาเทรนเนอร์ เลือกแพ็กเกจ และส่งคำขอจองบริการ

## ฟีเจอร์หลัก

- สมัครสมาชิกและเข้าสู่ระบบแบบ Demo
- แยกบริการใช้ฟิตเนสทั่วไปและฝึกกับเทรนเนอร์
- บันทึกข้อมูลสุขภาพ พร้อมคำนวณ BMI, BMR, TDEE, พลังงาน และโปรตีนต่อวัน
- ค้นหา กรอง ดูรายละเอียด และเลือกเทรนเนอร์
- ตรวจสอบสถานะใบรับรองของเทรนเนอร์ตัวอย่าง
- เลือกแพ็กเกจ ส่งคำขอจอง เช็กอิน และดูข้อมูลผ่าน Dashboard
- รองรับหน้าจอคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์

## วิธีเปิดใช้งาน

โปรเจกต์เป็นเว็บไซต์ HTML/CSS/JavaScript แบบ Static สามารถเปิด `index.html` ได้โดยตรง หรือเปิดผ่าน local server เช่น:

```bash
python -m http.server 8000
```

จากนั้นเปิด `http://localhost:8000`

## Google OAuth

ค่าเริ่มต้นทำงานใน Demo Mode หากต้องการเชื่อม Google OAuth จริง ให้ใส่ Web Client ID ใน `js/oauth-config.js` และตรวจสอบ ID token ผ่าน Backend ก่อนใช้งานจริง

## ขอบเขตของต้นแบบ

- ข้อมูลสมาชิกและรายการจองเก็บใน `localStorage`
- รายชื่อเทรนเนอร์และใบรับรองเป็นข้อมูลตัวอย่าง
- ยังไม่มีระบบชำระเงินจริง Backend ฐานข้อมูล และระบบอนุมัติของผู้ดูแล

## เทคโนโลยี

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
